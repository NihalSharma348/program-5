# Mandelbrot Set ASCII Renderer (C++)

A 19-line C++ program that draws the Mandelbrot set in the terminal using ASCII characters.

## How it works

For every point `c` on the complex plane, the program repeats `z = z^2 + c` starting from `z = 0`.

- If `|z|` goes above 2, the point escapes. The number of steps it took decides which character is printed.
- If `z` stays bounded for 30 iterations, the point is treated as part of the set and prints `@`.

The shade string is `" .:-=+*#%@"`. Fast escapes get light characters, slow escapes get dense ones.

## Requirements

- A C++ compiler with C++14 support (g++, clang++ or MSVC)
- A terminal at least 70 columns wide, with a monospaced font

## Build and run

```bash
g++ -std=c++14 mandel.cpp -o mandel
./mandel
```

On Windows (MinGW), run `mandel.exe` instead of `./mandel`.

## Customizing

| What to change | Where | Effect |
|---|---|---|
| Detail level | `i < 30` in `mandel()` (also the `/ 30` in `main`) | Higher value gives finer shading near the boundary |
| Resolution | step values `0.1` (y) and `0.04` (x) | Smaller steps give a bigger, sharper picture |
| Zoom area | start/end values of `x` and `y` | Zoom into different parts of the set |
| Look | `shades` string | Use different characters |

If you change the iteration limit, keep the `* 9 / 30` in `main` in sync with it (the 30 must match the limit, and 9 is the shade string length minus one).
